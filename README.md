# Cliente do Dia – Semana do Cliente Acessa Agro

Landing page estática (HTML + CSS + JS puro, sem build).

## Publicar
1. Suba esta pasta para um repositório no GitHub (com `index.html` na raiz).
2. Na Vercel: **Add New → Project**, importe o repositório, Framework Preset **Other**, sem build command, e clique em **Deploy**.

## Configurar
No final do `index.html`, edite o objeto `CONFIG`:
- `fimCampanha`: data/hora final do contador (ex.: `2027-09-21T23:59:59-03:00`)
- `links`: URLs dos botões (Quero aproveitar, Entrar, Ver mais ofertas, Regulamento, Privacidade, Fale conosco)

Imagens ficam em `assets/`.
